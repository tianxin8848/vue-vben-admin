# vue-vben-admin 国际化（i18n）文本切换说明文档

> 范围：`vue-vben-admin` 仓库（Vben Admin 5 + Vue 3 + vue-i18n），以 `apps/web-ele` 为主要示例应用。
> 本文梳理国际化文本切换的完整链路：语言包组织 → i18n 实例初始化 → 语言切换 UI → 消息加载/替换 → 第三方库联动 → 业务代码中使用。

## 2. 核心 i18n 包：`@vben/locales`

### 2.1 i18n 实例

[i18n.ts](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/locales/src/i18n.ts) 使用 Composition API 模式创建实例：

```ts
const i18n = createI18n({
  globalInjection: true,   // 模板中可直接用 $t
  legacy: false,           // 使用 Composition API（非 legacy）
  locale: '',              // 启动时由 setupI18n 注入默认值
  messages: {},
});
```

- `globalInjection: true` 使得所有组件模板中无需 `setup` 即可使用 `$t` / `$tc`。
- `legacy: false` 启用函数式 API，`i18n.global.locale` 是 `ref`，需用 `.value` 赋值。

### 2.2 语言包自动扫描

核心包通过 `import.meta.glob` 按目录结构自动收集 JSON 语言包：

```ts
const modules = import.meta.glob('./langs/**/*.json');
const localesMap = loadLocalesMapFromDir(
  /\.\/langs\/([^/]+)\/(.*)\.json$/,
  modules,
);
```

`loadLocalesMapFromDir` 会把 `./langs/zh-CN/common.json`、`./langs/zh-CN/ui.json` 等聚合为：

```ts
{
  'zh-CN': async () => ({ default: { common: {...}, ui: {...}, ... } }),
  'en-US': async () => ({ default: { common: {...}, ui: {...}, ... } }),
}
```

每个语言对应一个异步加载函数，实现**按需懒加载**（切换语言时才动态 import 对应 JSON）。

### 2.3 初始化 `setupI18n`

```ts
async function setupI18n(app: App, options: LocaleSetupOptions = {}) {
  const { defaultLocale = 'zh-CN' } = options;
  loadMessages = options.loadMessages || (async () => ({}));
  app.use(i18n);
  await loadLocaleMessages(defaultLocale);       // 预加载默认语言
  i18n.global.setMissingHandler((locale, key) => {
    if (options.missingWarn && key.includes('.')) {
      console.warn(`[intlify] Not found '${key}' key in '${locale}' locale messages.`);
    }
  });
}
```

- `defaultLocale`：默认语言，应用层从 `preferences.app.locale` 传入。
- `loadMessages`：应用层注入的回调，用于合并**应用自有语言包**和**第三方库语言包**。
- `missingWarn`：开发环境下找不到 key 时控制台告警。

### 2.4 切换语言 `loadLocaleMessages`

```ts
async function loadLocaleMessages(lang: SupportedLanguagesType) {
  if (unref(i18n.global.locale) === lang) {
    return setI18nLanguage(lang);          // 同语言只更新 html lang
  }
  setSimpleLocale(lang);                   // ① 同步简易 i18n（核心组件）
  const message = await localesMap[lang]?.();   // ② 加载核心语言包
  if (message?.default) {
    i18n.global.setLocaleMessage(lang, message.default);
  }
  const mergeMessage = await loadMessages(lang); // ③ 加载应用 + 第三方语言包
  i18n.global.mergeLocaleMessage(lang, mergeMessage);
  return setI18nLanguage(lang);            // ④ 切换 locale + 更新 <html lang>
}
```

`setI18nLanguage` 负责把 `i18n.global.locale.value` 设为新语言，并设置 `document.querySelector('html').setAttribute('lang', locale)`。

### 2.5 导出

[index.ts](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/locales/src/index.ts) 统一导出：

```ts
const $t = i18n.global.t;
const $te = i18n.global.te;
export { $t, $te, i18n, loadLocaleMessages, loadLocalesMap, loadLocalesMapFromDir, setupI18n };
export { useI18n } from 'vue-i18n';        // 组件内需响应式场景可使用
```

> 日常使用直接 `import { $t } from '@vben/locales'`；在 `<script setup>` 内若需要响应式 `t`，可用 `useI18n()`。

## 3. 语言包（JSON）组织结构

语言包为 JSON 文件，按「语言目录 + 命名空间文件」组织，文件名即顶层命名空间。

### 3.1 核心包语言包

```

├── zh-CN/
│   ├── authentication.json
│   ├── common.json        ← 通用按钮/操作：login、cancel、confirm…
│   ├── preferences.json   ← 偏好设置面板文案
│   ├── profile.json
│   └── ui.json
└── en-US/
    └── ...（同名文件）
```

示例 [common.json](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/locales/src/langs/zh-CN/common.json)：

```json
  "cancel": "取消",
  "confirm": "确认",
  "delete": "删除",
  "create": "新增"

```

### 3.2 应用层语言包

```
apps/web-ele/src/locales/langs/
├── zh-CN/
│   ├── demos.json
│   └── page.json          ← 业务页面/菜单文案
```

## 4. 应用层 i18n 装配（以 web-ele 为例）

[apps/web-ele/src/locales/index.ts](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/locales/index.ts) 完成三件事：

### 4.1 扫描应用语言包

```ts
const modules = import.meta.glob('./langs/**/*.json');
const localesMap = loadLocalesMapFromDir(/\.\/langs\/([^/]+)\/(.*)\.json$/, modules);
```

### 4.2 `loadMessages` 回调：合并应用包 + 第三方库

```ts
async function loadMessages(lang: SupportedLanguagesType) {
  const [appLocaleMessages] = await Promise.all([
    localesMap[lang]?.(),          // 应用自有语言包
    loadThirdPartyMessage(lang),   // 第三方库语言包
  ]);
  return appLocaleMessages?.default;
}
```

第三方库联动：

- **Element Plus**：通过 `elementLocale` ref 切换（传给 `<el-config-provider :locale="elementLocale">`）。
- **dayjs**：动态 `import('dayjs/locale/zh-cn')` 后调用 `dayjs.locale(...)`。

```ts
async function loadElementLocale(lang: SupportedLanguagesType) {
  switch (lang) {
    case 'en-US': elementLocale.value = enLocale; break;
    case 'zh-CN': elementLocale.value = defaultLocale; break;
  }
}
```

### 4.3 包装 `setupI18n`

```ts
async function setupI18n(app: App, options: LocaleSetupOptions = {}) {
  await coreSetup(app, {
    defaultLocale: preferences.app.locale,   // 从偏好读取默认语言
    loadMessages,                            // 注入应用 + 第三方加载逻辑
    missingWarn: !import.meta.env.PROD,      // 仅开发环境告警
    ...options,
  });
}
export { $t, elementLocale, setupI18n };
```

> 这里也可改造为从服务端获取翻译数据（注释已标注），把 `loadMessages` 换成接口请求即可。

### 6.1 header 语言切换按钮

### 6.2 偏好设置抽屉

[preferences.vue](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/effects/layouts/src/widgets/preferences/preferences.vue) 把偏好转成 `v-model` 双向绑定，当 `app.locale` 变更时自动联动：

```ts
const listen = computed(() => {
  const result: Record<string, any> = {};
  for (const [key, value] of Object.entries(preferences)) {
    if (typeof value === 'object') {
      for (const subKey of Object.keys(value)) {
        result[`update:${key}${capitalizeFirstLetter(subKey)}`] = (val: any) => {
          updatePreferences({ [key]: { [subKey]: val } });
          if (key === 'app' && subKey === 'locale') {
            loadLocaleMessages(val);          // 语言变更触发加载
          }
        };
      }
    }
  }
  return result;
});
```

## 7. 切换后刷新机制

[layout.vue](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/effects/layouts/src/basic/layout.vue) 监听 i18n locale 变化，刷新页面以保证所有组件重新渲染：

```ts
// 语言更新后，刷新页面
// i18n.global.locale 会在 preference.app.locale 变更之后才更新，
// 因此 watch preference.app.locale 不合适，刷新时语言可能尚未加载完成
watch(i18n.global.locale, refreshAll, { flush: 'post' });
```

`refreshAll` 会清空 tabbar 缓存并触发 `refresh()` 重新挂载当前路由组件。


### 11.4 组件内响应式（`useI18n`）

当需要在 `computed`/`watch` 中跟随语言切换自动更新时：

```ts
import { useI18n } from '@vben/locales';
const { t } = useI18n();
const label = computed(() => t('common.edit'));
```

> 全局 `$t` 是 `i18n.global.t`，已能响应语言变化；`useI18n()` 适合需要在局部作用域内使用插值参数、复数等场景。

## 12. 轻量 i18n：`useSimpleLocale`

部分 `@vben-core` 基础组件不希望耦合 vue-i18n，使用 [use-simple-locale](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/@core/composables/src/use-simple-locale/index.ts) 提供的简易翻译（基于本地 messages 表，找不到 key 时原样返回 key）：

```ts
export const useSimpleLocale = createSharedComposable(() => {
  const currentLocale = ref<Locale>('zh-CN');
  const setSimpleLocale = (locale: Locale) => { currentLocale.value = locale; };
  const $t = computed(() => {
    const localeMessages = getMessages(currentLocale.value);
    return (key: string) => localeMessages[key] || key;
  });
  return { $t, currentLocale, setSimpleLocale };
});
```

`loadLocaleMessages` 在切换时会调用 `setSimpleLocale(lang)` 同步它的语言，保证核心组件与主 i18n 一致。

## 13. 如何新增一种语言（例如 `ja-JP`）

1. **核心语言包**：在 `packages/locales/src/langs/` 下新建 `ja-JP/` 目录，复制 `zh-CN/` 下所有 JSON 并翻译。
2. **应用语言包**：在 `apps/web-ele/src/locales/langs/` 下新建 `ja-JP/`，同样复制并翻译。
3. **类型扩展**：在 [typing.ts](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/locales/src/typing.ts) 与 [core.ts](file:///Users/xi/Documents/github/7-13/vue-vben-admin/packages/constants/src/core.ts) 的 `LanguageOption.value` 中追加 `'ja-JP'`，并在 `SUPPORT_LANGUAGES` 数组加入 `{ label: '日本語', value: 'ja-JP' }`。
4. **第三方库**：
   - Element Plus：在 `loadElementLocale` 增加 `case 'ja-JP'`。
   - dayjs：在 `loadDayjsLocale` 增加 `case 'ja-JP'`，`import('dayjs/locale/ja')`。
   - vxe-table：在 `localMap` 增加 `'ja-JP': normalizeVxeLocale(jaJP)`。
5. 切换语言时 `loadLocaleMessages` 会自动通过 `import.meta.glob` 扫描到新 JSON，无需额外注册。

## 14. 如何新增一个翻译 key

1. 在对应语言包 JSON 中同时添加 zh-CN 与 en-US（保持 key 一致）：
   ```json
   // packages/locales/src/langs/zh-CN/common.json
   { "export": "导出" }
   // packages/locales/src/langs/en-US/common.json
   { "export": "Export" }
   ```
2. 业务代码使用 `$t('common.export')`。
3. 开发环境下若 key 缺失，控制台会输出 `[intlify] Not found '...'` 告警（由 `missingWarn` 控制）。

## 15. 注意事项

- **同语言重复切换**：`loadLocaleMessages` 检测到 `i18n.global.locale === lang` 时仅更新 `<html lang>`，不重新加载消息。
- **刷新时机**：语言切换后由 `layout.vue` watch `i18n.global.locale` 触发 `refreshAll`，不要改成 watch `preferences.app.locale`（此时语言包可能尚未加载完）。
- **命名空间冲突**：核心包与应用包通过文件名划分命名空间（`common`/`page`…），避免在不同层使用相同顶层 key。
- **懒加载**：语言包按需 import，首屏只加载默认语言，切换时才加载目标语言包。
- **持久化**：当前语言存储于 `preferences.app.locale`（偏好持久化），刷新页面后保留。
