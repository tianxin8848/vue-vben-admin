# 员工管理接口测试

> 接口文档地址：http://10.254.253.187:8999/docs#/员工管理
>
> 服务地址：`http://10.254.253.187:8999`
> 账号：`lin` / 密码：`Cisco@123`
> 认证方式：Cookie 会话（`SessionID`），登录后通过 `-b cookies.txt` 携带会话。

## 0. 登录（获取会话 Cookie）

```bash
curl -s -c cookies.txt -X POST "http://10.254.253.187:8999/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"lin","password":"Cisco@123"}'
```

> 登录成功后会写入 `cookies.txt`，后续所有接口通过 `-b cookies.txt` 携带会话。
> 当前 lin 账号的 `employee_id` 为 `6a2f6acd8d8c88ae7d154c29`，下文路径参数以此为例。

## 备注

- `lin` 账号无 `user_management` 权限，第二部分（员工管理）接口会返回 `{"detail":"当前用户无权访问员工列表"}` 之类的 403 错误；如需完整测试，请使用具备 `user_management` 权限的管理员账号登录。
- 第一部分（`/api/v1/me/*`）接口 lin 账号可正常访问。
- 头像上传接口（4、15）的 `@/path/to/avatar.jpg` 需替换为本地真实图片路径。
- 路径参数 `6a2f6acd8d8c88ae7d154c29` 为 lin 自己的 `employee_id`，测试其它员工时请替换为目标 `employee_id`。
