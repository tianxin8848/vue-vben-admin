## 五、报销管理模块

> 🆕 **架构变更**：报销引入「草稿 + 明细（line item）」模型。
> - `POST /api/v1/me/claims` 创建的是 **草稿（draft）**，需调用 `submit` 进入审批流。
> - 批量提交多条草稿会聚合为 **一条** pending 报销，每条草稿成为其中的一个明细项（`items`）。
> - Claim 对象移除 `invoice_date` / `invoice_no` 字段（票据信息不再在顶层）。
> - `ClaimApprovalStatus` 新增 `draft` 枚举值。
> - 审批支持部分驳回：`rejected_item_ids`。
> - 个人接口统一迁移到 `/api/v1/me/claims` 前缀。

## 状态流转说明

```
                 ┌─────────── DELETE (#42) ──────────┐
                 ▼                                    │
[创建 #37] ─► draft ──submit(#39/#40)──► pending ──approval(#45)──► approved
                 ▲                          │  │
                 │                          │  └──rejected──► rejected
                 └──── withdraw(#41) ───────┘
                                            │
                                            └────────► withdrawn
```

- **draft**：草稿，可删除（#42）、可提交（#39 批量 / #40 单条）
- **pending**：审批中，可撤回（#41）、可审批（#45 通过 / 驳回 / 部分驳回）
- **approved**：已通过
- **rejected**：已驳回
- **withdrawn**：已撤回

> 港币换算（`amount_hkd` / `exchange_rate_to_hkd`）仅在员工地区为「香港」时执行，地区为 null 或非「香港」时返回 null。
