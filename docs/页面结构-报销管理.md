# 报销管理页面结构总结

## 页面整体布局（从上到下）

```
┌─────────────────────────────────────────────┐
│  Page 容器 (v-loading)                       │
│  ┌─────────────────────────────────────────┐│
│  │  ElSegmented (Tab 切换)                  ││
│  │  [我的报销] [历史记录] [待我审批] [审批记录] ││
│  ├─────────────────────────────────────────┤│
│  │  用户信息文本（条件渲染）                 ││
│  │  当前用户：张三（zhangsan）               ││
│  ├─────────────────────────────────────────┤│
│  │  BasicTable (表格主体)                   ││
│  │  ┌─────────────────────────────────────┐││
│  │  │ Toolbar 工具栏                       ││
│  │  │  ┌──────────────┐  ┌─────────────┐  │││
│  │  │  │  表格标题      │  │ 新建报销申请 │  │││
│  │  │  │  我的报销（N条）│  │  [按钮]    │  │││
│  │  │  └──────────────┘  └─────────────┘  │││
│  │  ├─────────────────────────────────────┤││
│  │  │  表格内容区域（各列 slot 自定义渲染） │││
│  │  │  ...                                 │││
│  │  └─────────────────────────────────────┘││
│  └─────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────┐│
│  │  CreateClaimDrawer (新建抽屉)            ││
│  │  ReviewClaimDrawer (审批抽屉)            ││
│  └─────────────────────────────────────────┘│
└─────────────────────────────────────────────┘
```

## 1. 根容器

- **组件**：`<Page>`（来自 `@vben/common-ui`）
- **属性**：
  - `title="报销管理"` — 页面标题
  - `description="提交报销申请、查看审批进度与历史记录"` — 页面描述
  - `:auto-content-height="true"` — 自动撑满内容高度
  - `v-loading="loading"` — 全局 loading 遮罩

## 2. 主内容区

```html
<div class="flex h-full flex-col gap-2">
```

使用 flex 纵向布局，子元素间距 `gap-2`。

## 3. Tab 切换器

- **组件**：`<ElSegmented>`（Element Plus）
- **绑定**：`v-model="activeTab"`
- **选项**：
  - `我的报销` → `my`
  - `历史记录` → `history`
  - `待我审批` → `pending`
  - `审批记录` → `records`
- **默认激活**：`my`

## 4. 用户信息栏

- 条件渲染：仅在 `userInfo` 存在时显示
- 显示内容：`当前用户：{full_name}（{username}）`

## 5. 表格主体（BasicTable）

### 5.1 表格初始化

```ts
const [BasicTable, tableApi] = useVbenVxeGrid({
  gridOptions: {
    id: 'claim-index',
    rowConfig: { keyField: 'id' },
    columns: tabColumns.my,       // 初始为"我的报销"列配置
    proxyConfig: { enabled: false },
    height: 'auto',
    keepSource: true,
    toolbarConfig: sharedToolbarConfig,
  },
});
```

### 5.2 表格标题

- 通过 `:table-title="activeTableTitle"` 绑定
- 根据当前 Tab 动态显示：`我的报销（N 条）`、`历史记录（N 条）` 等

### 5.3 工具栏（Toolbar）

**共享工具栏配置**：

```ts
const sharedToolbarConfig = {
  custom: true,   // 允许列自定义
  tools: [{
    code: 'manual-refresh',
    icon: 'vxe-icon-refresh',
    circle: true,
    name: '刷新',
  }],
};
```

### 5.4 「新建报销申请」按钮位置

```
位置：BasicTable 的 #toolbar-tools 插槽内
```

```html
<BasicTable :table-title="activeTableTitle" class="min-h-0 flex-1">
  <template #toolbar-tools>
    <ElButton
      v-if="activeTab === 'my'"
      type="primary"
      @click="openCreateDrawer"
    >
      新建报销申请
    </ElButton>
  </template>
</BasicTable>
```

**关键特征**：
- **所在层级**：`BasicTable` 组件的 `#toolbar-tools` 插槽
- **显示条件**：`v-if="activeTab === 'my'"` — 仅在「我的报销」Tab 下可见
- **按钮类型**：`type="primary"`（主色调按钮）
- **点击行为**：调用 `openCreateDrawer()` → 打开 `CreateClaimDrawer` 抽屉
- **视觉位置**：表格工具栏右侧区域（表格标题右侧）

### 5.5 四套 Tab 列配置

| Tab | 列字段 | 特殊列 |
|-----|--------|--------|
| `my` | reason_label, amount, description, approval_status, created_at, attachment_url | 附件列 |
| `history` | reason_label, amount, description, approval_status, review_comment, created_at | 审批意见列 |
| `pending` | employee_name, reason_label, amount, description, created_at, (操作) | 操作列（审批按钮） |
| `records` | employee_name, claim_reason_label, amount, action, comment, created_at | 操作+备注列 |

### 5.6 列 Slot 映射

| Slot 名 | 渲染内容 |
|---------|---------|
| `reason` | 报销理由（my/history 用 `strong` 加粗） |
| `amount` | 金额 + 货币符号 + 港币换算 |
| `description` | 说明文本，空值显示 `-` |
| `status` | 状态 Tag（success/warning/danger/info） |
| `created_at` | 格式化日期时间 |
| `attachment` | 附件链接 |
| `review_comment` | 审批意见 |
| `employee` | 申请人姓名 + 用户名 |
| `action` | 审批按钮（仅 pending Tab） |
| `record_action` | 操作类型 Tag（审批记录） |
| `comment` | 备注文本 |

## 6. 弹窗抽屉

### CreateClaimDrawer（新建报销）

- 位置：`<Page>` 根容器内，`<BasicTable>` 后方
- 绑定：`:currency-options` 和 `:reason-options`
- 事件：`@success` → 刷新数据

### ReviewClaimDrawer（审批）

- 位置：`<Page>` 根容器内，`<BasicTable>` 后方
- 事件：`@success` → 刷新审批数据

## 7. 数据流

```
onMounted
  └── fetchAll()
        ├── loadOptions()          → reasonOptions, currencyOptions
        ├── loadUserInfo()         → userInfo
        ├── loadMyClaims()        → myClaims
        ├── loadMyHistory()       → myHistory
        ├── loadPendingApprovals()→ pendingApprovals
        └── loadApprovalRecords() → approvalRecords
  └── refreshTable()              → 更新表格 columns + data

watch(activeTab)
  └── reloadActiveTab()           → 按需加载对应 Tab 数据 + refreshTable()
```

## 总结

「新建报销申请」按钮位于表格工具栏的 **右侧** 区域，通过 `BasicTable` 的 `#toolbar-tools` 插槽放置，仅在「我的报销」Tab 激活时显示。页面整体结构为：Page 容器 → Segmented Tab → 用户信息 → BasicTable（含工具栏+表格）→ 两个 Drawer 抽屉。
