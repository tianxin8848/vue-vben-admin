

## 整体布局

```
Page (标题: "我的请假")
├── 顶部操作栏
├── 我的请假记录 (ElCard)
├── 我的请假年历 (ElCard)
└── 填写请假单 (Modal)
```

## 2. 我的请假记录（ElCard）
[index.vue#L315-L463](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/views/leave/list/index.vue#L315-L463)

**头部操作区：**
- 标题：「我的请假记录」
- 刷新列表按钮
- 切换显示全部/隐藏撤回与驳回

**表格（ElTable）：**
- 展开行：点击行可展开查看详情（请假说明、工作交接人、当前审批人、最近处理、请假天数、创建时间），审批中状态还提供「查看详情」和「撤回申请」按钮
- 列：日期范围、请假类型（Tag）、时段（Tag）、状态（Tag 不同颜色）、创建时间

## 3. 我的请假年历（ElCard）
[index.vue#L465-L657](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/views/leave/list/index.vue#L465-L657)

**头部：**
- 标题：「我的请假年历」
- 年份导航：上一年 / 当前年份标签 / 下一年 / 回到今年

**统计卡片（5 格 Grid）：**
[index.vue#L530-L608](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/views/leave/list/index.vue#L530-L608)
- 当年请假记录数、当年覆盖天数、待审批记录数、当年年假总计、当年年假可用

**年历面板：**
- 使用 `CalendarPanel` 组件（来自 `../calendar/components/CalendarPanel.vue`），按年展示每天的请假分布

**日期详情区：**
- 选中日期后展示当天的请假记录明细（类型、时段、状态、说明）

---

## 4. 填写请假单（Modal）
[index.vue#L659-L727](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/views/leave/list/index.vue#L659-L727)

使用 `useVbenModal` 封装的弹窗表单，字段包括：
- 请假类型（下拉选择）
- 开始日期、结束日期（日期选择器）
- 请假时段（全天/上午/下午）
- 工作交接人（输入框）
- 请假说明（多行文本）

---

## 总结

该页面是一个 **单页垂直布局**，从上到下依次为：
1. **操作按钮** → 2. **请假记录表格**（可展开详情、可撤回）→ 3. **年历视图**（年份切换 + 统计卡片 + 日历 + 日期详情）→ 4. **弹窗表单**
