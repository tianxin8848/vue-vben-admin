### 改了什么

[index.vue](file:///Users/xi/Documents/github/7-13/vue-vben-admin/apps/web-ele/src/views/system/settings/index.vue) 做了以下修改：

1. **`ColPage` → `Page`**：移除了左右分栏布局，改用与报销页面一致的 `Page` 组件（来自 `@vben/common-ui`），添加 `:auto-content-height="true"`

2. **单一 `ElSegmented` 控制 5 个 Tab**：原来的 `ElSegmented` 嵌套在左侧 `ElCard` 内部，现在提升到顶层，新增了 `当前预览` 选项：
   - 基础参数 (`basic`) — 部门/岗位/地区/模块编辑
   - 员工字段 (`employee`) — 员工可自编辑字段
   - 报销配置 (`claim`) — 报销理由/币种
   - 地区假期 (`holiday`) — 假期维护/名称清单
   - 当前预览 (`preview`) — 原 `SettingsPreview` 组件（汇总表、地区假期表、名称清单表）

3. **布局结构**：参照报销页面的模式，使用 `flex h-full flex-col gap-2` 容器，`ElSegmented` 固定顶部，内容区通过 `min-h-0 flex-1` 自适应

### 现在的界面结构

```
Page (标题 + 描述)
└── ElSegmented (5个Tab平铺切换)
    ├── 基础参数 → ElCard + SettingsForm
    ├── 员工字段 → ElCard + EmployeeEditableFieldsEditor
    ├── 报销配置 → ElCard + ClaimReasonEditor + CurrencyEditor
    ├── 地区假期 → ElCard + HolidayEditor + HolidayCatalogEditor
    └── 当前预览 → SettingsPreview (3个表格)
```

不再有左右分栏，所有内容通过顶部 Tab 切换控制。
